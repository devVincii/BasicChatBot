# chatbotl

This is my chatbot designed to handle basic medical queries and requests. I’ve included comments for each block of code to help those who are new to machine learning understand how it works.

This is only a very basic version of the bot. Over the next few hours, I’ll be uploading an improved version that uses spaCy instead of NLTK, which should boost accuracy significantly and of course the aim is atleast 70%. The datasets will also be updated—in fact, I plan to spend more time improving the training data than on the model architecture itself, making only small tweaks to the model to enhance performance.
